# 边界矩阵与准出用语

准出对象 = 系统级设计方案（文档/基线）。不签原理图（schematic-review 的职责），
不签 PCB。

## 结果状态

| 状态 | 含义 |
|---|---|
| PASS | 有出处且符合 |
| FAIL | 证据证明存在问题 |
| INSUFFICIENT | 适用但缺需求/功耗/可靠来源 |
| NA | 有依据确认不适用（写依据，不拿 NA 掩盖缺口） |

A/B/C 只用于独立的证据置信度，与结果状态无关；C 级不得推出 A/B 结论。

## 边界矩阵

| 域 | 方案可判定 | 移交 HANDOFF | 本 skill 不判定 |
|---|---|---|---|
| 电源 | 轨结构/来源/负载、选型、时序逻辑、裕量、保护方案 | 上电实测、热测试、去耦数量细则 | PDN、PCB 压降、布局热路径 |
| 接口/外设 | 协议、电平、引脚分配、带宽预算 | SI 阻抗/等长约束、连接器机械 | 眼图、串扰、EMC 实测 |
| EMC/安规 | 防护选型、泄放拓扑、隔离与接地策略 | 布局位置、屏蔽、爬电间距约束 | 辐射/传导认证结果 |
| 器件 | 选型身份、降额、电气/封装兼容 | 采购、库存、生命周期 | 焊盘钢网装配工艺 |
| 可靠性 | 方案应力预算、默认态、失效安全 | FMEA、寿命/筛选试验 | 完整鉴定 |
| 测试 | 调试口、测试点、烧录方案 | ICT/夹具 | 覆盖率实测 |

## HANDOFF 语义

HANDOFF 不是审查结果，是冻结基线时写给下游（原理图绘制、PCB、结构、测试）的可
执行约束：`required` / `state`（OPEN/ACCEPTED/VERIFIED）/ `receivers` / `constraint`
/ `verification`。约束未形成或无接收方 = 阻断冻结。

## 与 schematic-review 的交接

本 skill 的“意图清单 + 移交约束”即 schematic-review 第 0 步“设计意图问卷”的输入。
绘制阶段对基线的任何改动（加器件、改轨、换接口）必须回本 skill 闭环，避免基线漂移。

## 准出用语

允许：

- 系统方案可冻结并进入原理图设计。
- 系统方案有条件冻结，须先关闭列出的关键 INSUFFICIENT 项。
- 系统方案不可冻结，存在 BLOCKER 或未接受 Warning。

禁止：

- 原理图可冻结进 PCB（那是 schematic-review 的措辞）。
- 整板可投板。
- SI/PI、EMC、热、DFM 已通过（除非另有对应审查证据，本报告只作外部引用）。
