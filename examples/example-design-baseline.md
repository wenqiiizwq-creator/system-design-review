# Design Baseline：合成辅助电源示例

> 仅为数据契约演示。器件模型、需求及工程师确认均为虚构，不能用于真实电路设计。
> 对应 design-intent-v2.json；版本 SYNTHETIC-1，变体 fixture-only。

## 状态摘要

合成记录可通过机械门禁；真实工程未审查、未获确认。示例只演示受控输入下稳态，
不声称覆盖任何真实硬件全部工况。真实项目须建立适用启动、复位、故障与环境条件。

## 意图、实现和约束

| 类别 | 主张 | 来源 |

| 意图 R1 | 在 12V 输入下连续提供 5V/0.5A | 虚构需求 S1 §1 |

## 接口与工况

J1：本板为 DC source，对端负载为 sink，5V 电源域。RUN 工况为受控 12V 稳态带载。
模型不包含软件控制或复位电路，不据此输出冷启动/掉电/保护通过结论。

## 决策与确认

保留独立辅助电源作为合成拓扑，不扩展优化；D1 标 protected 仅演示保留约束。
JSON 的 SYNTHETIC_ENGINEER 记录是测试 fixture，不是 Agent 可在真实任务中代填的模板值。

## 如何看测试结果

十层计划和结果用于示范字段与关联，不能以这种简短总述替代真实项目的逐对象检查。
完整 JSON 用于正向机器回归；资料缺失、未确认、版本变化等负向行为见 scripts/tests。
